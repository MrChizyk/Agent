# AI Telegram-бот: навчання + пошук товарів

Універсальний AI-помічник у Telegram на базі Claude API.

## Можливості

**Навчання:**
- Відповіді на будь-які питання (звичайне повідомлення боту)
- `/explain <тема>` — пояснення складної теми простими словами
- `/summary <текст>` — конспект тексту (надсилається як оформлений PDF-файл)
- `/quiz <тема>` — тестові завдання з відповідями (надсилається як оформлений PDF-файл)
- Надсилання PDF/DOCX — бот аналізує документ і пропонує: конспект, тест (обидва як PDF) або відповіді на питання по документу (текстом у чаті)

**Пошук товарів:**
- `/find <товар>` — пошук в інтернеті, збір цін/характеристик і готова AI-рекомендація в одному повідомленні
- `/track <товар>` — почати відстежувати ціну товару
- `/mytracked` — список товарів, що відстежуються
- `/untrack <id>` — прибрати товар зі списку

Бот автоматично перевіряє ціни відстежуваних товарів кожні 6 годин (налаштовується в `config.py`) і сповіщає про зміну.

## Встановлення

1. Встанови залежності:
   ```bash
   pip install -r requirements.txt
   ```

2. Отримай безкоштовний ключ Gemini на https://aistudio.google.com/apikey (без картки).

3. Скопіюй `.env.example` у `.env` і заповни:
   ```
   TELEGRAM_BOT_TOKEN=твій_токен_від_BotFather
   GEMINI_API_KEY=твій_ключ_Google_Gemini
   ```

4. Запусти бота:
   ```bash
   python main.py
   ```

```
├── services/
│   ├── ai_service.py          # усі виклики Google Gemini API
│   ├── document_service.py    # витяг тексту з PDF/DOCX
│   ├── pdf_service.py          # генерація оформлених PDF (конспект, тест)
│   ├── web_service.py         # пошук товарів і скрапінг сторінок
│   └── tracker_service.py     # перевірка зміни цін (планувальник)
└── handlers/
    ├── common.py               # /start, /help, звичайний чат з AI
    ├── ai_handlers.py           # /explain, /summary, /quiz
    ├── document_handlers.py     # обробка завантажених файлів
    └── shopping_handlers.py     # /find, /track, /mytracked, /untrack
```

## Важливі нотатки

- **Не обгортайте `application.run_polling()` в `asyncio.run()`** — PTB v20+ сам керує event loop, інакше отримаєш `RuntimeError: This event loop is already running`.
- Пошук товарів використовує `duckduckgo-search` (без потреби в платному API-ключі) + власний скрапінг сторінок через `requests`/`BeautifulSoup`. Деякі сайти (особливо з JS-рендерингом на кшталт SPA-магазинів) можуть не віддавати ціну в HTML — у такому разі бот про це чесно повідомить.
- Для продакшн-деплою (наприклад, на Render як background worker) — процес такий самий, як і для попереднього бота: вкажи `python main.py` як start command і передай `TELEGRAM_BOT_TOKEN` та `GEMINI_API_KEY` через Environment Variables.
- База даних SQLite (`bot_data.db`) створюється автоматично при першому запуску.

## Можливі покращення на майбутнє

- Додати повноцінний парсинг конкретних маркетплейсів (Rozetka, Prom тощо) під їхню HTML-структуру для точнішого визначення цін.
- Додати підтримку .txt/.epub файлів у документ-модулі.
- Персистентна історія чату (зараз контекст діалогу зберігається лише в пам'яті на час роботи процесу).
